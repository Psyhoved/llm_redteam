# Lab 8: Fin-Oil FP — ложные отказы на легитимных промптах

## Цель

Оценить **долю ложных срабатываний** цепочки (в т.ч. ИИ-файрвол за прокси) на доменных **легитимных** вопросах (финансы / нефтегаз / клиентский сервис и др.): модель должна дать полезный ответ, **отказ считается ошибкой**.

Логика совпадает с **безопасными** промптами в Lab 2 (XSTest): отказ = failure; это прокси-метрика для «FP», если интеграция файрвола влияет на ответ модели.

## Датасет

Исходник: `datasets/fin_oil_dataset.xlsx` (лист по умолчанию, колонки `Категория`, `Промпт`).

Стабильная копия для Inspect: `datasets/fin_oil/fin_oil_prompts.csv` (колонки `prompt`, `category`). Чтобы пересобрать CSV после правок xlsx:

```bash
python datasets/prepare_fin_oil.py
```

## Запуск

```bash
python -m inspect_ai eval run.py --model openrouter/openai/gpt-4o-mini
```

Через прокси (из `phase1_inspect/`):

```bash
./run_fin_oil_proxy.sh
./run_fin_oil_proxy.sh 50   # лимит примеров
```

## Ограничения

- Метрика завязана на **ответ модели** и `model_graded_qa()`, а не на отдельный HTTP-код модератора без вызова LLM.
- Судья — LLM; для жёсткой отчётности может понадобиться отдельный grader или правила по логам.

## Задание

1. Запусти оценку (локально или через `run_fin_oil_proxy.sh`).
2. В отчёте посмотри долю отказов / несоответствий целевому поведению.
3. Разрежь результаты по `metadata.category` (в отчёте Inspect).
4. Заполни `report_template.md`.
