# Lab 1 (Phase 2): OWASP LLM Top-10 Dynamic Red Teaming

## Цель

Протестировать модель по всем поддерживаемым угрозам OWASP LLM Top-10 (2025)
с помощью динамически генерируемых атак.

## Чем отличается от Phase 1?

| Phase 1 (Inspect AI) | Phase 2 (DeepTeam) |
|----------------------|--------------------|
| Фиксированные датасеты | Атаки генерируются в реальном времени |
| Воспроизводимые результаты | Результаты варьируются между запусками |
| Покрывает известные атаки | Адаптируется к конкретной модели |
| Измеряет ASR по датасету | Измеряет соответствие OWASP категориям |

## Задание

1. Запусти тест (займёт 5–15 минут):
   ```bash
   python run.py
   ```

2. Открой JSON-отчёт в `../../reports/` и найди:
   - Уязвимости с наименьшим pass rate
   - Примеры успешных атак по каждой OWASP категории

3. Сравни результаты с Phase 1 на той же модели.

4. Заполни `report_template.md`.

## OWASP угрозы в DeepTeam

- **LLM01 Prompt Injection** — вставка инструкций через ввод пользователя
- **LLM02 Sensitive Information Disclosure** — утечка конфиденциальных данных
- **LLM05 Improper Output Handling** — небезопасная обработка вывода модели
- **LLM06 Excessive Agency** — модель выполняет действия за пределами допустимого
- **LLM07 System Prompt Leakage** — утечка системного промпта
- **LLM09 Misinformation** — генерация дезинформации
- **LLM10 Unbounded Consumption** — неограниченное потребление ресурсов
